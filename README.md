## ⚡ Core Highlights

- **Aesthetic**: Production Neo-Brutalism with high-contrast palette (Electric Lime #c8f560, Bubblegum Pink #ff85a1, Royal Purple #7053ff, stark borders and sharp drop-shadows).
- **Zero Privacy Leaks**: Securely sanitized asset streams ensuring no personal phone numbers, addresses, or private credentials are exposed.
- **Fast & Responsive**: Built with Vite + TypeScript, zero runtime bloat, sub-second loads, and pure CSS Tailwind utility tokens.
- **Direct Accreditations**: Verified links to credentials, certifications, technical project repositories, and resume PDF downloads.

## 🚀 Local Development

To run this project locally:

`ash
# Clone the repository
git clone https://github.com/Devansh7006/Devansh-portfolio.git
cd Devansh-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
`

Build for production:

`ash
npm run build
npm run preview
`
